# 使用指南

**语言：** [English](USAGE.md) · [日本语](USAGE.ja.md) · 简体中文 · [Español](USAGE.es.md) · [हिन्दी](USAGE.hi.md) · [العربية](USAGE.ar.md) · [한국어](USAGE.ko.md) · [Русский](USAGE.ru.md) · [Français](USAGE.fr.md)

本应用在 Android 手机上运行 Quantus Network（QTC 主网）的**非验证者全节点**。它同步区块链、自行验证每一个区块，并向对等节点中继数据。它**不挖矿**，也**没有钱包**——从不接触助记词或奖励密钥。

> 当前状态：v3.0 已发布（2026-11-11，当前版本，DePIN 集成版）。签名 APK 已在 [GitHub Releases](https://github.com/ogaworld369/quantus-android-node/releases) 上提供，并附带 SHA-256 校验和。此前的测试版本由维护者直接提供。

## 系统要求

- Android 12 或更高版本，arm64 设备
- 可用存储空间：节点数据库经过修剪（仅保留最近 256 个区块），体积较小。实测（Pixel 9a，完整同步后，2026-11-05）：总计 1.30 GB（应用 96 MB + 节点数据 1.20 GB）。作为参考，请预留至少约 3 GB 可用空间
- 互联网连接。首次同步强烈建议使用 Wi-Fi（见下文）

已验证设备：**运行 GrapheneOS 的 Pixel 9a**。其他设备预计可以运行，但尚未验证。如果您在其他机型上尝试，请通过 GitHub Issue 报告结果（无论成功与否）——已验证列表正是靠这些报告不断扩充的。

## 安装

1. 从 [GitHub Releases](https://github.com/ogaworld369/quantus-android-node/releases) 获取 APK 文件（安装前请核对随发布提供的 SHA-256 校验和）。
2. 用“文件”应用打开 APK，Android 询问时允许从该来源安装。
3. 安装后打开 **Quantus Node**。

## 首次运行与初次同步

1. （可选）先设置**显示名称**和**遥测**选项（见“设置”）。设置变更需要重启节点（停止 → 启动）才能生效。
2. 点击**启动节点**。
3. 状态会显示**同步中**，最佳区块向最高区块攀升。在 Pixel 9a 上，从创世区块开始的首次同步约为每秒 50 个区块——请预计**约 2 小时**。同步完成后，大约每 12 秒到达一个新区块，状态变为已同步。
4. 首次同步期间，请尽量让手机**保持充电并连接 Wi-Fi**。通过移动数据同步也可以，但会下载大量数据且耗电明显更多（实测：移动数据同步时 30 分钟约消耗 11% 电量）。同步完成后的持续负载很小。

无需一直开着应用。节点作为前台服务运行：关屏或使用其他应用时仍会继续运行，运行期间会显示常驻通知。停止后再启动，同步会从中断处继续——已下载的链数据保存在设备上。

## 界面说明

应用底部有三个标签页：主页、连接、会员卡。节点详情和设置从主页进入。

- **主页** — 脉冲、节点状态（已停止／启动中／同步中／已同步／失败）和一个主按钮。节点运行期间，还会显示已连接的对等节点数、本次运行时间和当前 QTC 价格。涟漪仅在节点已同步、且首次观察到新的最佳区块时安静地出现一次。如果启动失败，主页会将其显示为失败并提供重试按钮，而不是普通的停止；如果您更改的设置尚未生效，主页会显示查看该设置的链接
- **连接** — 生动呈现本节点网络图景的界面：所连接的对等节点，以及本机记录的检查点回响。这里展示的是连接关系，而不是用来攀比的数字——没有排名
- **节点详情** — 最佳区块 / 最高区块（您的节点所在位置与已知网络顶端的对比）、同步差距、对等节点数和运行时间，以及**诊断**部分：退出代码、服务备注、每次启动尝试的记录和**分享日志**（见下文）。节点停止时，此界面显示的是您的累计轨迹记录，而不是上一次运行的数值
- **会员卡** — 您的会员卡：会员编号（设备 ID）和本机记录的代表数字——累计运行时间、观察到的新区块数、观察到的对等节点最大值。记录仅保存在本机，永不上传，也不具有金钱价值——它只是您自己的贡献足迹，是否出示由您决定
- **设置** — 以下设置；应用版本显示在最下方

## 设置

- **在遥测中显示**（默认关闭）— 开启后，您的节点名称和实时状态将在官方遥测页面 telemetry.quantus.com 上公开可见。仅在您希望被列出时开启。从下次节点启动时生效（停止 → 启动）。
- **显示名称** — 节点使用的名称（启用遥测时也会显示在列表中），在对话框中编辑。留空则使用默认名称 `quantus-android-node`。从下次节点启动时生效。
- **语言** — 跟随设备设置，或从 9 种语言中选择（日语、英语、简体中文、西班牙语、印地语、阿拉伯语、韩语、俄语、法语）。选择后立即生效。
- **记录我的活动（DePIN）**（默认关闭）— 开启后，应用会把节点的在线与中继工作的签名记录保存在本机（每 10 分钟一个检查点）。记录不会自行发送到任何地方；您可以从“设置”将其导出为证明包文件并自行分享。关闭后停止记录，已有记录保留在设备上
- **锁定设置** — 将上面的设置（遥测、显示名称、语言和活动记录）锁定，以免手机在持续运行节点时被误触更改。这只是防误触功能，没有 PIN 码，节点的启动与停止永远不会被锁定。需要更改设置时，关闭 **锁定设置** 即可。

设置不会自行重启节点。如果在节点运行期间更改了遥测或显示名称，被更改的项目会在设置中标记为尚未生效，主页也会显示查看待生效设置的链接；更改将在下次节点启动时（停止 → 启动）生效。

**分享日志** 位于 **节点详情 → 诊断** 中：它以文本形式分享节点日志，报告问题时请附上它。在公开场合粘贴日志前，请先检查内容：日志中可能包含本节点的公网 IP 地址和对等节点信息。分享对话框可以对显示名称、本机自身的接口地址和应用私有路径进行掩码处理（默认开启）；节点通过对等节点获知的外网地址不在掩码范围内。

## 日常运行

- 节点只会在以下情况停止：点击**停止节点**、强制停止应用、或重启手机。
- 重启手机后，请打开应用再次点击**启动节点**——开机自动启动尚未实现。
- 某些厂商的 Android 版本（Samsung、小米等）省电策略较激进，可能会停止后台服务。如果节点总是被停止，请在系统设置中将本应用排除在电池优化之外。
- 把闲置手机 24 小时插着电使用？请时不时检查电池状态——老化的锂电池可能会鼓胀。请把手机放在通风处；如果设备提供充电上限设置，建议开启。

## 遇到问题时

- **节点立即退出** — 打开**节点详情 → 诊断 → 分享日志**，将日志附在 GitHub Issue（缺陷报告模板）中发送。日志记录了每次启动尝试及其结束原因。
- **对等节点一直为 0** — 检查网络连接，然后停止 → 启动一次。
- **同步停滞（网络在前进，但您的最佳区块不动）** — 应用检测到这种形态后会自行重启节点（24 小时内最多 3 次）。如果反复出现，换到稳定的 Wi-Fi 后再停止 → 启动一次
- **您的节点没有出现在遥测中** — 确认遥测选项已开启，且开启后重启过节点。（列表显示已确认可用：维护者自己的节点已出现在官方列表中。）
- **关于存储** — 数据库按设计修剪为最近 256 个区块。卸载应用会删除数据库和节点的身份密钥；重新安装会以新身份重新同步。

问题、设备报告和建议都欢迎提交 GitHub Issue。安全问题请按 [SECURITY.md](../SECURITY.md) 的流程报告，不要发公开 Issue。
