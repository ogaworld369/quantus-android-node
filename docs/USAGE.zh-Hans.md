# 使用指南

**语言：** [English](USAGE.md) · [日本语](USAGE.ja.md) · 简体中文 · [Español](USAGE.es.md) · [हिन्दी](USAGE.hi.md) · [العربية](USAGE.ar.md) · [한국어](USAGE.ko.md) · [Русский](USAGE.ru.md) · [Français](USAGE.fr.md)

本应用在 Android 手机上运行 Quantus Network（QTC 主网）的**非验证者全节点**。它同步区块链、自行验证每一个区块，并向对等节点中继数据。它**不挖矿**，也**没有钱包**——从不接触助记词或奖励密钥。

> 当前状态：预发布（Phase 1 MVP）。尚无公开版本；测试版本由维护者直接提供。公开发布开始后，签名 APK 将在 GitHub Releases 上发布，并附带 SHA-256 校验和。

## 系统要求

- Android 12 或更高版本，arm64 设备
- 可用存储空间：节点数据库经过修剪（仅保留最近 256 个区块），设计上体积较小。设备上的确切大小仍在测量中——作为参考，首次同步请预留约 10 GB 可用空间
- 互联网连接。首次同步强烈建议使用 Wi-Fi（见下文）

已验证设备：**运行 GrapheneOS 的 Pixel 9a**。其他设备预计可以运行，但尚未验证。如果您在其他机型上尝试，请通过 GitHub Issue 报告结果（无论成功与否）——已验证列表正是靠这些报告不断扩充的。

## 安装

1. 获取 APK 文件（目前由维护者提供；公开发布开始后从 GitHub Releases 获取——安装前请核对随发布提供的 SHA-256 校验和）。
2. 用“文件”应用打开 APK，Android 询问时允许从该来源安装。
3. 安装后打开 **Quantus Node**。

## 首次运行与初次同步

1. （可选）先设置**显示名称**和**遥测**选项（见“设置”）。设置变更需要重启节点（停止 → 启动）才能生效。
2. 点击**启动节点**。
3. 状态会显示**同步中**，最佳区块向最高区块攀升。在 Pixel 9a 上，从创世区块开始的首次同步约为每秒 50 个区块——请预计**约 2 小时**。同步完成后，大约每 12 秒到达一个新区块，状态变为已同步。
4. 首次同步期间，请尽量让手机**保持充电并连接 Wi-Fi**。通过移动数据同步也可以，但会下载大量数据且耗电明显更多（实测：移动数据同步时 30 分钟约消耗 11% 电量）。同步完成后的持续负载很小。

无需一直开着应用。节点作为前台服务运行：关屏或使用其他应用时仍会继续运行，运行期间会显示常驻通知。停止后再启动，同步会从中断处继续——已下载的链数据保存在设备上。

## 界面说明

- **状态** — 同步中／已同步；每次到达新的最佳区块时，脉冲视图会出现一次安静的涟漪
- **最佳区块 / 最高区块** — 您的节点所在位置与已知网络顶端的对比
- **对等节点** — 您连接到的节点数量
- **轨迹** — 仅保存在本机的记录：累计运行时间、观察到的新区块数、观察到的对等节点最大值。不会上传，也不具有金钱价值——只是您自己贡献的足迹
- **量子观察** — 自身节点的同步状态与网络连接健康状况（外部威胁情报尚未实现）

## 设置

- **在遥测中显示**（默认关闭）— 开启后，您的节点名称和实时状态将在官方遥测页面 telemetry.quantus.com 上公开可见。仅在您希望被列出时开启。从下次节点启动时生效（停止 → 启动）。
- **显示名称** — 节点使用的名称（启用遥测时也会显示在列表中）。留空则使用默认名称 `quantus-android-node`。从下次节点启动时生效。
- **语言** — 跟随设备设置，或从 9 种语言中选择（日语、英语、简体中文、西班牙语、印地语、阿拉伯语、韩语、俄语、法语）。
- **分享日志** — 以文本形式分享节点日志。报告问题时请附上它。

设置不会自行重启节点。在节点运行期间更改设置，界面会提示需要重启（停止 → 启动）。

## 日常运行

- 节点只会在以下情况停止：点击**停止节点**、强制停止应用、或重启手机。
- 重启手机后，请打开应用再次点击**启动节点**——开机自动启动尚未实现。
- 某些厂商的 Android 版本（Samsung、小米等）省电策略较激进，可能会停止后台服务。如果节点总是被停止，请在系统设置中将本应用排除在电池优化之外。
- 把闲置手机 24 小时插着电使用？请时不时检查电池状态——老化的锂电池可能会鼓胀。请把手机放在通风处；如果设备提供充电上限设置，建议开启。

## 遇到问题时

- **节点立即退出** — 在设置中点击**分享日志**，将日志附在 GitHub Issue（缺陷报告模板）中发送。日志记录了每次启动尝试及其结束原因。
- **对等节点一直为 0** — 检查网络连接，然后停止 → 启动一次。
- **您的节点没有出现在遥测中** — 确认遥测选项已开启，且开启后重启过节点。（列表显示行为仍在验证中。）
- **关于存储** — 数据库按设计修剪为最近 256 个区块。卸载应用会删除数据库和节点的身份密钥；重新安装会以新身份重新同步。

问题、设备报告和建议都欢迎提交 GitHub Issue。安全问题请按 [SECURITY.md](../SECURITY.md) 的流程报告，不要发公开 Issue。
